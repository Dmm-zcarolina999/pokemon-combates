# Plataforma de Combates Pokémon

Videojuego de combates por turnos en terminal. Los jugadores eligen criaturas,
usan habilidades, gestionan sus puntos de vida y se enfrentan entre sí.

Proyecto de clase de Entornos de Desarrollo (1º DAM).

## Cómo ejecutar

    python src/main.py

## Cómo ejecutar los tests

    python -m unittest discover tests

## Estructura

- `src/` código del juego
- `data/` archivos CSV (criaturas, habilidades, historial)
- `tests/` tests con unittest
- `docs/` documentación
